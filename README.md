# Séquenceur synesthésique

Ouvrez ce dossier dans VS Code puis lancez `index.html` dans un navigateur (ou avec Live Server).

La version conserve le style initial : animation topographique pastel, liste de 10 instruments et piano roll avec table de mixage. Les réglages sont neutres au démarrage : volume 70 %, panoramique centre, réverbération 0 %, delay 0 %.

Pour créer une note longue, placez une première note avec un clic, puis maintenez la touche **Maj** enfoncée et cliquez les cellules consécutives à droite. Les cellules liées apparaissent dans une nuance plus légère et sont jouées comme une note continue.
